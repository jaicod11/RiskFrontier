# Frontend

Vite + React + TypeScript + Tailwind client for the Portfolio Risk Tool.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # typecheck + production build to dist/
```

Set `VITE_API_BASE_URL` in `.env` (see `.env.example`) to point at the backend.

See the [root README](../README.md) for the full stack and local setup.
